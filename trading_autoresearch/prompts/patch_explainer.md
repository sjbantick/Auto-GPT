# Patch Explainer

Summarize the following candidate patch for a human reviewer.

## Input

{{ patch_diff }}
{{ hypothesis }}
{{ scorecard_result }}

## Output

1. **What changed** (2-3 sentences)
2. **Why** (the hypothesis)
3. **Key metrics** (table of before/after)
4. **Risk assessment** (1-2 sentences)
5. **Recommendation**: promote / hold / reject
